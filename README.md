# Questwright

An AI game studio that lives in this repo. Read [CLAUDE.md](CLAUDE.md) for how it works.

```bash
npm install          # once
npm run gates        # all quality gates for lib + every game
```

Slash commands (in Claude Code, from this folder): `/new-game`, `/build-milestone`, `/feedback`, `/release`.

Games live in `games/<slug>/`; shared systems in `lib/`.
